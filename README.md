# Liquid-Glass-Notes 🌊

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Description

Liquid-Glass-Notes is a beautifully designed, modern, and visually appealing note-taking application with a unique "liquid glass" aesthetic. It offers a fluid and intuitive user experience for creating, organizing, and managing your thoughts. The application features animated backgrounds, subtle glassmorphism effects, and smooth transitions, making note-taking a delightful experience.

## Features ✨

- **Liquid Glass UI:** A visually stunning interface with frosted glass effects, smooth animations, and a gradient background.
- **Dynamic Backgrounds:** Animated gradients and floating orbs create an immersive and calming atmosphere.
- **Intuitive Note Management:** Easily create, edit, search, and organize notes.
- **Color Customization:** Assign different color themes to your notes for better organization.
- **Search Functionality:** Quickly find notes by title or content.
- **Pinning Notes:** Pin important notes to keep them easily accessible at the top of the list.
- **Rich Text Formatting:** Basic formatting options like bold, italic, and underline.
- **Word Count:** Real-time word count display for active notes.
- **Auto-Save:** Notes are automatically saved to local storage.
- **Responsive Design:** Adapts to different screen sizes (though primarily designed for desktop viewing).
- **Keyboard Shortcuts:** For efficient note creation (Ctrl/Cmd + N) and pinning (Ctrl/Cmd + P).

## Tech Stack 💻

- **Languages:** HTML, CSS, JavaScript
- **Frameworks/Libraries:** Tailwind CSS (via CDN for styling)
- **Other:** HTML5 APIs (localStorage)

## Installation 🚀

This project is a single-file HTML application and does not require a complex installation process. You can run it directly from your browser.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/iIluminatixy/Liquid-Glass-Notes.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Liquid-Glass-Notes
   ```
3. **Open `index.html`:**
   Open the `index.html` file in your web browser.

No build tools or external dependencies are required as all necessary files (including Tailwind CSS via CDN) are included directly in the `index.html` file.

## Usage 📝

Liquid-Glass-Notes is designed for personal note-taking, idea capture, and quick journaling. Its aesthetic appeal makes it a pleasure to use for everyday thoughts, to-do lists, or even drafting short pieces of content.

**Key Use Cases:**

- **Daily Journaling:** Capture your thoughts and reflections in a beautiful and serene environment.
- **Idea Capture:** Quickly jot down ideas as they come to you, with easy organization and search.
- **Task Management:** Use it as a simple to-do list manager, color-coding tasks by priority or category.
- **Quick Notes:** Ideal for taking notes during meetings or lectures, with easy formatting options.

## How to Use 💡

1.  **Open `index.html`:** Access the application by opening the `index.html` file in your web browser.
2.  **Create a New Note:** Click the "New Note" button in the sidebar to create your first note.
3.  **Edit Title and Content:** Use the input fields to add a title and write your note content. Basic formatting (bold, italic, underline) is available via the toolbar.
4.  **Customize Color:** Select a color from the color picker in the toolbar to assign a theme to your note. This helps in visual organization.
5.  **Pin Notes:** Click the pin icon in the toolbar to pin important notes. Pinned notes will appear at the top of the note list.
6.  **Search Notes:** Use the search bar in the sidebar to filter notes by title or content.
7.  **Delete Notes:** Use the delete button (trash can icon) on individual notes in the sidebar or within the editor to remove them.
8.  **Auto-Save:** Your notes are automatically saved locally in your browser's `localStorage` as you type.
